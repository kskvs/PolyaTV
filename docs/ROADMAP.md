# Roadmap

## Stage 0 — Исследование интеграций

**Статус: исследование исходников завершено; прямой сценарий PolyaTV → нативный выбор файла MatriX не подтверждён.** Подробности и альтернативы — в [INTEGRATIONS.md](INTEGRATIONS.md).

- [x] Проверить публичные исходники API/Activity TorrServe MatriX, Android TV SearchProvider Lampa.
- [x] Установить фактическое различие `action=play` и `action=choose`; исправить прежние ошибочные выводы в документации.
- [x] Зафиксировать для NUM отсутствие подтверждённого внешнего контракта; системные рекомендации оставить гипотезой до проверки на ТВ.
- [x] Записать способы получения данных, ограничения и обходные пути по всем трём источникам.
- [ ] На Philips проверить реальные версии приложений, Lampa provider, NUM recommendations и переходы по intent.
- [ ] Проверить API/ответы реального TorrServe, включая его версию, авторизацию, каталог, поиск и file chooser.
- [ ] Проверить историю, resume и продолжение просмотра по реальным данным.
- [ ] Проверить источники постеров/metadata, лицензии и attribution.

**Критерий завершения этапа 0:** для каждого источника указан проверенный путь к данным и безопасному chooser либо документировано, что сценарий не подтверждён, вместе с альтернативой. Этот критерий исследования выполнен. Не означает, что интеграции или playback реализованы.

## Этап 1 — Основа приложения

Рабочая основа по решению пользователя — форк Arc Launcher (Flutter/Dart, происхождение LTvLauncher/FLauncher), сохранить историю и GPL-3.0. Этап не начат в рамках этого исследования.

- [ ] Изучить и форкнуть Arc с сохранением истории и LICENSE.
- [ ] Указать происхождение и GPL-3.0 в README и документации.
- [ ] Переименовать приложение и applicationId.
- [ ] Проверить сборку и запуск на эмуляторе и Philips.
- [ ] Проверить D-pad фокус/возврат и базовые настройки.

## Этап 2 — Минимальный прототип витрины

- [ ] После технической проверки выбрать первый реализуемый источник.
- [ ] Добавить один ряд постеров отдельным модулем, не ломая функции Arc.
- [ ] Реализовать требуемый безопасный hand-off в штатный MatriX picker. Сейчас прямой контракт не подтверждён, поэтому этот пункт заблокирован результатом этапа 0 и требует выбора/проверки альтернативы.
- [ ] Проверить D-pad на телевизоре без потери фокуса.

## Этап 3 — Остальные источники

- [ ] Подключать Lampa и NUM по одному только после проверки их реального контракта на устройстве.
- [ ] Сохранять переход к источнику, если прямой hand-off в MatriX недоступен.
- [ ] Не считать capability-адаптер NUM рабочим без результата на конкретной прошивке.

## Этап 4 — Единая витрина

- [ ] Hero-баннер, горизонтальные ряды и единый поиск.
- [ ] Дедупликация и настройки секций.
- [ ] История/продолжение только из реально доступных и подтверждённых источников.
- [ ] Плавная D-pad-навигация и восстановление фокуса после возврата из приложения.

## Этап 5 — Companion и выпуск

- [ ] Windows Companion — только после стабильных этапов 0–4 и отдельного согласования.
- [ ] Сборка, проверки установки/обновления, документация и release workflow.
