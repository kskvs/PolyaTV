# Roadmap

## Stage 0 — Исследование интеграций

**Статус: критерий исследования выполнен 2026-11-09; прямой сценарий PolyaTV → нативный выбор файла MatriX не подтверждён.** По TorrServe и Lampa описаны доступные контракты и обходные варианты; по NUM честно отмечено отсутствие подтверждённого внешнего контракта. Это результат аудита исходников, не проверка установленных приложений на Philips. Подробности — в [INTEGRATIONS.md](INTEGRATIONS.md).

- [x] Проверить публичные исходники API/Activity TorrServe MatriX, Android TV SearchProvider Lampa.
- [x] Установить фактическое различие `action=play` и `action=choose`; исправить прежние ошибочные выводы в документации.
- [x] Зафиксировать для NUM отсутствие подтверждённого внешнего контракта; системные рекомендации оставить гипотезой до проверки на ТВ.
- [x] Записать способы получения данных, ограничения и обходные пути по всем трём источникам.
- [x] На Philips подтверждены установленные пакеты и версии: TorrServe MatriX 144 (`ru.yourok.torrserve`), Lampa 7.7.9-115 (`ru.twicker.lampa`) и NUM 1.0.151 (`ru.yourok.num`). PolyaTV получил из системного Watch Next TV Provider 94 записи; прямой запрос через shell не даёт содержимое provider, поэтому проверка состава по источникам ещё нужна.
- [x] На установленном NUM обнаружен receiver для `INITIALIZE_PROGRAMS`, `PREVIEW_PROGRAM_ADDED_TO_WATCH_NEXT` и связанных событий TV Provider. Это подтверждает обработку Android TV recommendation lifecycle, но само по себе не подтверждает, что NUM публикует карточки в Watch Next на этой прошивке.
- [ ] Проверить, какие из 94 записей Watch Next принадлежат TorrServe, Lampa и NUM, и проверить переходы по их реальным карточкам.
- [ ] Проверить реальный TorrServe endpoint, авторизацию, каталог, поиск и file chooser.
- [ ] Проверить историю, resume и продолжение просмотра по реальным данным.

**Критерий завершения этапа 0:** для каждого источника указан проверенный путь к данным и безопасному chooser либо документировано, что сценарий не подтверждён, вместе с альтернативой. Этот критерий исследования выполнен. Не означает, что интеграции или playback реализованы.

## Этап 1 — Основа приложения

Рабочая основа — Arc Launcher (Flutter/Dart, происхождение LTvLauncher/FLauncher). История Arc влита отдельным merge-коммитом и GPL-3.0 сохранена. Переименование продукта и release applicationId выполнено. GitHub Actions run 110 на коммите `36959e0` успешно выполнил `flutter analyze`, `flutter test`, сборку debug APK и загрузку артефакта. Анализатор завершает работу с ошибкой при error-level diagnostics; существующие Arc info/warnings выводятся, но не блокируют CI.

Физическая проверка 2026-11-10 на Philips 50PUS8057/60 (Android 11, API 30): debug APK `tv.polya.app.debug` установлен и запущен; Activity осталась активной. Проверены D-pad вправо/влево/вниз, распознавание HOME intent и восстановление фокуса на карточке после выхода из системных настроек. В журнале после запуска нет `FATAL EXCEPTION`. Google TV Launcher имеет больший приоритет для HOME; выбор PolyaTV основным лаунчером не менялся.

**Этап не завершён:** Android TV эмулятор и настройки самого PolyaTV ещё не проверены. Локальные Flutter/JDK отсутствуют.
