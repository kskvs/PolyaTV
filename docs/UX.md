# UX и D-pad-навигация

## Визуальная идея
Кинотеатральная композиция со своей дизайн-системой: выразительный hero, постерные ряды, портретные и широкие карточки, читаемые подписи и осторожные градиенты. Контент важнее декоративных эффектов.

## Фокус и движение
Основной UX-риск — дрожание интерфейса и потеря фокуса.
- стабильные ключи элементов;
- фокус привязан к ID контента, а не позиции в изменяемом списке;
- обновление одного ряда не должно пересоздавать весь экран;
- после обновления восстанавливать элемент по content ID;
- анимация не должна менять layout так, чтобы вызывать повторные скачки;
- избегать конкурирующих вложенных focus groups;
- тестировать D-pad, Back и возврат из внешних приложений.

Увеличение карточки, тень, подсветка и лёгкая глубина допустимы, но умеренны и настраиваемы. Нужны отключение анимации и регулировка интенсивности/скорости.

## Навигация
Начальный вариант — сбалансированная предсказуемая навигация: движение внутри ряда, переходы между рядами, запоминание последнего элемента каждого ряда, восстановление позиции после возврата и отсутствие тупиков между секциями.

## Сценарии проверки
Длинный ряд; переходы между рядами разной ширины; обновление сфокусированного ряда; возврат из TorrServe/Lampa/NUM; скрытие сфокусированного элемента; медленная сеть; быстрые повторные нажатия D-pad.
